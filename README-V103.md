# AVAN GALLERY V103 — D1 Support Center

این نسخه پشتیبانی آنلاین آوان را به D1 وصل می‌کند.

## قابلیت‌ها
- دکمه شناور پشتیبانی با تم سرمه‌ای/طلایی آوان
- چت آنلاین مشتری → D1
- تیکت پشتیبانی → D1
- پاسخ مدیر از پنل `/admin/dashboard`
- پاسخ چت مدیر به‌صورت polling هر ۴ ثانیه
- نمایش پاسخ‌های مدیر در چت مشتری
- مدیریت وضعیت تیکت: باز / در حال بررسی / بسته
- شمارنده تیکت/چت جدید در منوی پنل مدیریت

## مهاجرت D1
بعد از قرار دادن فایل‌ها در GitHub، یک بار این دستور را اجرا کنید:

```bash
npx wrangler d1 execute avan-gallery-db --remote --file=./schema.sql
```

سپس Deploy:

```bash
npx wrangler deploy
```

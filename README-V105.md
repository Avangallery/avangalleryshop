# AVAN GALLERY V105 — Premium Admin Dashboard + Products

این نسخه بر پایه V104 ساخته شده و مسیرهای فعلی، لاگین، D1، پشتیبانی و ساختار پروژه را حفظ می‌کند.

## تغییرات
- بازطراحی کامل داشبورد مدیریت با تم سرمه‌ای/طلایی AVAN GALLERY
- Hero مدیریتی، KPIهای واقعی بر اساس محصولات D1، نمودار ۷ روزه و وضعیت فروشگاه
- نمایش آخرین محصولات در داشبورد
- دکمه‌های سریع برای مدیریت محصولات و پشتیبانی
- بازطراحی صفحه مدیریت محصولات با هدر حرفه‌ای، آمار موجودی، فیلتر پیشرفته، جستجو و جدول/کارت ریسپانسیو
- حفظ CRUD محصولات و اتصال فعلی `/api/products`
- حفظ پشتیبانی تیکت و چت
- بدون R2 جدید
- سازگار با موبایل و دسکتاپ

## ورود
مسیر فعلی `/admin` حفظ شده است.

## مهم
این نسخه را قبل از Deploy با همان تنظیمات فعلی Worker/D1 پروژه منتشر کنید.

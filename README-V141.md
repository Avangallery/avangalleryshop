# AVAN GALLERY V141 — No-scroll quick links

این نسخه بر پایه V139 تهیه شده و لینک‌های سریع فوتر را اصلاح می‌کند. با کلیک روی صفحه اصلی، محصولات، درباره ما، تماس با ما، سؤالات متداول یا حریم خصوصی، یک پنجره روی همان صفحه باز می‌شود؛ هیچ anchor jump، تغییر آدرس hash یا scrollIntoView اجرا نمی‌شود و جای صفحه ثابت می‌ماند. پنجره با دکمه بستن، کلیک روی پس‌زمینه یا Escape بسته می‌شود.

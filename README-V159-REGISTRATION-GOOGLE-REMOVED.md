# AVAN GALLERY V159 — ثبت‌نام عادی و حذف ورود گوگل

- رابط ورود/ثبت‌نام فقط از ایمیل و رمز عبور استفاده می‌کند؛ دکمه‌ها و مسیرهای OAuth گوگل از صفحه و Worker حذف شده‌اند.
- ثبت‌نام از `/api/auth/register` و ورود از `/api/auth/login` استفاده می‌کند.
- کلید امضای نشست از `AUTH_SESSION_SECRET`، سپس `ADMIN_SECRET` و در نهایت `ADMIN_PASSWORD` استفاده می‌کند؛ وابستگی به GOOGLE_CLIENT_SECRET حذف شده است.
- پیام خطاهای جدول `users` دقیق‌تر شده تا مشکل مهاجرت D1 قابل تشخیص باشد.
- طراحی سرمه‌ای/سفید حفظ شده و فیلدها با زمینه سفید و متن سرمه‌ای واضح‌اند.

## مهم
به دیتابیس زنده و لاگ‌های Cloudflare دسترسی مستقیم ندارم؛ بنابراین ثبت‌نام روی D1 فعلی پس از Deploy باید بررسی شود. اگر خطا ماند، متن خطای جدید و لاگ `Customer authentication failed` را ببینید.

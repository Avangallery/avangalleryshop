# AVAN GALLERY V161 — اصلاح پشتیبانی، FAQ و لینک‌های فوتر

بر پایه فایل ZIP آخری که کاربر ارائه کرده ساخته شده است.

- اتصال دکمه شناور پشتیبانی و دکمه پشتیبانی فوتر به پنل پشتیبانی
- فعال‌سازی تب‌های چت آنلاین، ثبت تیکت و راه‌های ارتباطی
- فعال‌سازی بستن پنل پشتیبانی از ×، پس‌زمینه و Escape
- اصلاح باز و بسته شدن پنل سؤالات متداول و حریم خصوصی
- اصلاح بازگشت/بستن پنجره‌ها و بازگرداندن فوکوس به کنترل قبلی
- بهبود لایه‌بندی، انیمیشن ملایم و نمایش پنل‌ها روی موبایل
- لینک‌های سریع فوتر به بخش‌های واقعی صفحه هدایت می‌شوند
- چت نمایشی، ارسال واقعی به سرور نیست؛ پیام این موضوع را شفاف نشان می‌دهد.

اعتبارسنجی: اسکریپت‌های درون صفحه با `node --check` بررسی شدند. ZIP باید پس از انتشار روی سایت زنده به‌صورت دستی آزمایش شود.

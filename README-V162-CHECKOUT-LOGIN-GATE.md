# AVAN GALLERY V162 — ورود اجباری پیش از خرید

- صفحه checkout قبل از نمایش فرم، وضعیت `/api/auth/me` را بررسی می‌کند.
- اگر کاربر وارد نشده باشد، به `/login.html?next=%2Fcheckout.html` هدایت می‌شود.
- پس از ورود یا ثبت‌نام موفق، به مقصد داخلی `next` بازمی‌گردد؛ اگر مقصد امن نباشد، صفحه حساب کاربری باز می‌شود.
- API ثبت سفارش نیز نشست معتبر می‌خواهد و برای درخواست ناشناس پاسخ 401 می‌دهد.
- پس از ورود، مشتری در صفحه checkout می‌تواند اطلاعات ارسال را وارد کند و سپس روش پرداخت آنلاین یا کارت‌به‌کارت را انتخاب کند.
- این تغییرات به ساختار D1 یا تنظیمات Cloudflare دست نمی‌زنند و از R2 استفاده نمی‌کنند.

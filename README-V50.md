# AVAN GALLERY V50

## Structure
- `index.html` — storefront shell
- `login.html` — authentication page
- `css/components/products.css` — product catalog UI
- `css/components/menu-cart.css` — hamburger/cart UI
- `js/app.js` — header, drawer, cart, search and product interactions
- `assets/` — images and local brand SVGs

No R2 dependency is introduced.

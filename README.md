# AVAN GALLERY V1

نسخه اولیه فروشگاه فارسی و RTL آوان گالری.

## اجرا
فایل `index.html` را باز کنید یا پروژه را روی GitHub قرار دهید.

## Cloudflare Pages
Build command: خالی
Build output directory: `/`

این نسخه برای Cloudflare Pages به صورت Static آماده شده و از R2 استفاده نمی‌کند.

## نکته
محصولات نمونه داخل `assets/js/app.js` هستند. برای اتصال واقعی به دیتابیس، احراز هویت، سفارش و درگاه پرداخت باید Backend/Cloudflare Workers + D1 اضافه شود.

# AVAN GALLERY — No R2

نسخه کامل فروشگاه آوان گالری برای Cloudflare Workers + D1، **بدون Cloudflare R2**.

تصاویر این نسخه فقط از:
- URLهای خارجی
- یا فایل‌های استاتیک داخل `public/`

استفاده می‌کنند و هیچ binding یا dependency به R2 ندارند.

## راه‌اندازی
1. `npm install`
2. `npx wrangler login`
3. `npx wrangler d1 create avan_gallery`
4. شناسه D1 را در `wrangler.jsonc` قرار دهید.
5. `npm run db:remote`
6. برای اجرای محلی: `npm run dev`
7. برای انتشار: `npm run deploy`

سایت: `/`
پنل مدیریت: `/admin.html`

بعد از ساخت حساب مشتری، نقش آن را در D1 به `admin` تغییر دهید:
`UPDATE users SET role='admin' WHERE phone='شماره مدیر';`

## نکته
این پروژه از R2 استفاده نمی‌کند. برای فروش واقعی، درگاه پرداخت، SMS و سرویس‌های خارجی در صورت نیاز باید با API/Secretهای خودتان اضافه شوند.

### تصاویر
برای محصول می‌توانید در پنل مدیریت URL تصویر قرار دهید. همچنین می‌توانید تصاویر ثابت را داخل `public/images/` قرار دهید و URL آن‌ها را با `/images/name.jpg` تنظیم کنید.

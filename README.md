# AVAN GALLERY Functional Header V2
همه کنترل‌های هدر/هیرو دارای رفتار واقعی هستند:
- منو و زیرمنو
- جستجو
- اسلایدر خودکار و دکمه‌های اسلاید
- سبد خرید و علاقه‌مندی با localStorage
- دکمه‌های خدمات
- لینک‌های بخش‌ها
- منوی موبایل
- نمونه افزودن محصول

این نسخه مستقل از پروژه MR MOBILE است و R2 نیاز ندارد.
